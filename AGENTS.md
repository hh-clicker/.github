# Инструкция агенту

## Назначение и границы

Публичный профиль организации, пользовательское руководство и release workflow HH Clicker.

## Карта кода

- `profile/README.md` — полное руководство, отображаемое на главной организации.
- `.github/workflows/release.yml` — сборка Windows EXE, Linux AppImage, macOS Intel/ARM DMG и draft-релиза по тегу `v*`.
- `.github/workflows/macos-release.yml` — общий reusable workflow двух stable macOS-сборок.
- `RELEASING.md` — порядок выпуска и проверка артефактов.

## Инварианты

- Руководство описывает действия пользователя и фактические названия элементов UI.
- Ссылку скачивания показывай после публикации настоящего installer.
- Не сохраняй скрытые планы публикации и протоколы ручных прогонов в Markdown.
- Workflow получает launcher по соответствующему тегу, пять сервисов — по pinned SHA.
- Выпуск создаётся draft; не публикуй его автоматически.
- Не переписывай опубликованные теги и не подменяй состав выпущенного релиза.
- Не логируй credentials и значения secrets; не включай локальные данные в артефакты.

## Проверка и документация

Проверяй локальные ссылки, якоря, YAML и встроенный PowerShell без запуска release workflow.
Изменение workflow согласовывай с каталогом `launcher/releases` и installer pipeline.
Пользовательские шаги сверяй с UI и документацией компонентов. Коммиты и теги релиза подписываются.
