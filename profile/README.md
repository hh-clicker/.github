<a name="about"></a>
## Что умеет HH Clicker

HH Clicker — локальное приложение для Windows, которое помогает организовать поиск работы
на hh.ru: сохранить поиски, собрать вакансии, разобрать предложения и управлять очередью откликов.

| Возможность | Для чего нужна |
| --- | --- |
| 🔎 Сохранённые поиски | Запускать сбор по ссылкам HH с вашими фильтрами |
| 🗂️ Каталог вакансий | Просматривать предложения, отмечать избранное и формировать очередь |
| 🚫 Стоп-лист компаний | Исключать работодателей для одного резюме или для всех аккаунтов |
| 🎯 AI-оценка | Разбирать релевантность вакансий под выбранное резюме |
| ✉️ Сопроводительные письма | Использовать обычный текст или AI-шаблон с индивидуальной серединой |
| ▶️ Очередь откликов | Отправлять выбранные отклики с лимитом и паузами, видеть результаты |
| 📄 Холостой запуск | Сохранять полные тексты вакансий без писем и отправки откликов |
| 📊 Аналитика рынка | Получать MD-отчёт по технологиям, навыкам и доменам в сохранённом срезе |
| 🔔 Уведомления | Следить за событиями через браузер, звук и собственного Telegram-бота |

Приложение использует два окна: **лаунчер** управляет окружением, а **веб-интерфейс**
предназначен для работы с вакансиями. Отдельный управляемый Google Chrome нужен для действий на HH.

<a name="start"></a>
## Быстрый старт

Если хотите сначала разобраться в основном сценарии:

1. [Установите приложение](#install) и откройте **HH Clicker Launcher**.
2. [Подготовьте окружение](#launcher) по подсказкам лаунчера, затем нажмите **«Запустить»**.
3. Когда сервисы будут готовы, нажмите **«Открыть HH Clicker»**.
4. В разделе **«Резюме»** [добавьте аккаунт HH и выберите резюме](#accounts).
5. В разделе **«Поиски»** [сохраните ссылку поиска HH и запустите сканирование](#searches).
6. В разделе **«Вакансии»** просмотрите результаты и выберите подходящие предложения.
7. Для знакомства с обработкой сначала используйте [холостой запуск](#dry-run): он сохранит тексты,
   а вакансии останутся в очереди.
8. Когда будете готовы отправлять отклики, [настройте письмо и запустите реальную очередь](#applications).

**AI подключается отдельно.** Для обычных писем и работы с каталогом авторизация Codex не нужна.
Для AI-писем, оценки релевантности и аналитики понадобится [подключить Codex](#codex).

<a name="install"></a>
## 1. Требования и установка

### Что понадобится

| Компонент | Назначение |
| --- | --- |
| Windows x64, Linux x86_64 или macOS 14+ | Операционная система для лаунчера и Browser Agent; для macOS есть Intel и Apple Silicon |
| Аппаратная виртуализация | Нужна окружению WSL 2 и Docker; включается в BIOS/UEFI |
| WSL 2 и Docker Desktop | Запускают локальные сервисы и базу данных |
| Google Chrome | Используется для управляемого профиля HH |
| Интернет | Скачивание компонентов, работа с hh.ru и AI |
| Аккаунт соискателя hh.ru | Вход на HH и выбор собственных резюме |
| Доступ к Codex | Нужен при использовании AI-функций |

Лаунчер проверяет зависимости и предлагает следующие действия. Заранее вручную устанавливать
все компоненты из таблицы не обязательно: ориентируйтесь на результаты проверки.

Для установки компонентов Windows может понадобиться подтверждение администратора и перезагрузка.
Сам HH Clicker устанавливается для текущего пользователя.

### Как установить

Выбирайте файл для своей системы: `.exe` для Windows, `.AppImage` для Linux,
`macos-arm64.dmg` для Apple Silicon или `macos-x64.dmg` для Intel Mac.
Установка и обновление описаны отдельно для
[Linux](https://github.com/hh-clicker/launcher/blob/master/LINUX.md) и
[macOS](https://github.com/hh-clicker/launcher/blob/master/MACOS.md). Шаги ниже относятся к Windows.

1. Откройте [страницу последнего релиза](https://github.com/hh-clicker/.github/releases/latest).
2. В блоке **Assets** скачайте файл `HH-Clicker-Setup-<версия>.exe`.
3. Запустите установщик и завершите установку.
4. Откройте **HH Clicker Launcher** через созданный ярлык или меню «Пуск».

Файлы **Source code (zip)** и **Source code (tar.gz)** — это исходники, не готовое приложение.
Для обычной установки выбирайте EXE.

<details>
<summary><strong>Нужно ли устанавливать Java, PostgreSQL, Git или Codex CLI?</strong></summary>

Для работы установленного комплекта не нужно самостоятельно устанавливать JDK, Gradle,
PostgreSQL, nginx или Codex CLI: нужное окружение входит в приложение и его контейнеры.
Git нужен для работы с исходниками, а не для обычной установки через EXE.

Для Browser Agent нужен Node.js на Windows. Если совместимый Node.js уже установлен,
лаунчер использует его; иначе может подготовить отдельный локальный runtime.

</details>

<a name="launcher"></a>
## 2. Лаунчер и первый запуск

### Подготовьте компьютер

Если Google Chrome устанавливается впервые, после установки один раз откройте его вручную и завершите
первоначальную настройку. Это относится к Windows, Linux и macOS. Затем вернитесь в лаунчер
и нажмите «Проверить снова».

В экране **«Подготовка компьютера»** выполняйте предлагаемое действие и повторяйте проверку,
пока окружение не будет готово. Лаунчер последовательно проверяет виртуализацию, WSL,
Docker, Node.js, Chrome и необходимые файлы.

| Что показывает проверка | Что сделать |
| --- | --- |
| Нужна настройка WSL | Выполнить предложенное действие и перезагрузить Windows, если это запрошено |
| Не найден Docker Desktop | Ознакомиться с условиями и подтвердить установку |
| Docker установлен, но не запущен | Запустить его через предложенное действие и дождаться готовности |
| Используется неподходящий режим Docker | Переключить Docker Desktop на WSL 2 и Linux containers |
| Не найден Chrome | Использовать предложенную установку либо установить Chrome самостоятельно |
| Занят порт | Нажать **«Выбрать свободные порты»**, если это действие предложено |

Изменение режима уже установленного Docker может потребовать ручных действий в его настройках.
Лаунчер показывает пояснение для обнаруженной ситуации.

### Запустите сервисы

1. Дождитесь состояния **«Готов к запуску»**.
2. Нажмите **«Запустить»**.
3. Дождитесь готовности компонентов.
4. Нажмите **«Открыть HH Clicker»** — откроется адрес интерфейса вашей установки.

Первый запуск может занять заметно больше времени: скачиваются зависимости и образы,
подготавливаются сервисы. Это отличается от обычного открытия уже настроенного приложения.

### Как завершать работу

Перед остановкой окружения проверьте активные отклики, сканирование и анализы.
Для управления сервисами используйте действие **«Остановить»** в лаунчере.
Закрытие веб-вкладки само по себе не является командой остановки очереди.

> [!TIP]
> Открывайте интерфейс кнопкой лаунчера. Адрес и порт могут отличаться от примеров
> в чужих инструкциях, особенно если при настройке были заняты стандартные порты.

<a name="accounts"></a>
## 3. Аккаунты HH и резюме

### Добавьте аккаунт

1. Перейдите в **«Резюме»** и нажмите **«Добавить аккаунт»**.
2. Укажите понятное локальное название, например «Основной HH».
3. Нажмите **«Создать и продолжить»**.
4. В панели настройки нажмите **«Открыть браузер»**.
5. В открывшемся управляемом Chrome войдите в нужный аккаунт hh.ru.
6. Вернитесь в HH Clicker и нажмите **«Я вошёл — найти резюме»**.
7. Отметьте нужные резюме и нажмите **«Добавить выбранные»**.

Название аккаунта используется внутри HH Clicker. Создание такой записи не создаёт новый аккаунт на hh.ru.

### Проверьте импортированный текст

В карточке резюме показаны его название, связь с HH и сохранённый текст. Изображения и контактные
блоки при импорте не загружаются. Именно сохранённый текст используется в дальнейших AI-сценариях.

После изменений на HH проверьте, какой текст сейчас отображается в HH Clicker:
не считайте, что локальная копия автоматически обновилась вместе с сайтом.

Чтобы загрузить новую копию, выберите резюме на странице **«Резюме»** и нажмите **«Обновить текст с HH»**.
Настройки писем и автоматизации сохранятся. Если загрузка не удалась, прежний текст останется доступным.

Для добавления резюме в существующий аккаунт используйте **«Загрузить из HH»**.
В панели выбора доступна кнопка **«Обновить список»**.

### Переключение аккаунтов и резюме

В верхней части интерфейса выберите аккаунт и резюме, с которыми собираетесь работать.
Проверьте этот выбор перед созданием поиска, запуском откликов и анализом.

Поиск привязывается к резюме. Письма и настройки автоматизации тоже задаются для выбранного резюме.
Стоп-лист может быть как локальным для резюме, так и общим — [подробнее ниже](#stoplist).

### Управляемый Chrome

В разделе **«Браузер»** доступны:

- **«Запустить браузер»** — открыть профиль выбранного аккаунта;
- **«Проверить вход»** — проверить текущую авторизацию HH;
- **«Остановить браузер»** — закрыть управляемый браузер.

Если для выбранного действия нужен закрытый управляемый браузер, приложение откроет его автоматически.

### Диагностика страниц HH

При ошибке чтения страницы в поиске, откликах или загрузке резюме нажмите **«Открыть диагностику»**.
На странице **«Браузер»** появятся инструкция и кнопка **«Проверить проблемную вкладку»**.
Если вкладка закрыта, откройте нужную страницу заново и используйте **«Выбрать вкладку»**.
Полная диагностика для исправления одного шага не требуется.

Кнопка **«Полная диагностика»** проверяет профиль, печатное резюме, поиск и вакансию из выдачи.
Проверка читает текущую страницу, не отправляет отклики и не открывает формы отправки.
Для проверки уже открытой формы выберите её вкладку вручную.

При подтверждённой поломке чтения и подключённом Codex можно исправить селекторы с помощью ИИ.
Используется GPT-6 Sol с уровнем рассуждений medium; два запроса могут занять несколько минут
и расходуют лимиты Codex. Исправление сохраняется локально после проверки на странице.
После успешной проверки вернитесь к исходному действию и повторите его.
Капча, недоступная вакансия и мешающий попап не требуют ИИ-починки.

Вход в обычном личном Chrome не означает вход в профиле HH Clicker. Авторизацию и капчу
проходите в управляемом окне. После ручного входа или выхода нажмите **«Проверить вход»**:
индикатор показывает результат последней проверки, а не непрерывное наблюдение за сессией.

<a name="codex"></a>
## 4. Подключение Codex

Codex используется для AI-писем, оценки релевантности, аналитики и помощника на страницах тестов.
Вход в hh.ru и вход в Codex — два независимых подключения.

1. Запустите окружение через лаунчер.
2. Откройте **«Настройки»** лаунчера и блок авторизации Codex.
3. Нажмите **«Войти через ChatGPT»** и следуйте показанным шагам: откройте официальную страницу и введите одноразовый код.
4. Завершите вход в аккаунт с доступом к Codex.
5. Дождитесь подтверждения в лаунчере.
6. В веб-интерфейсе откройте AI-настройки резюме и при необходимости нажмите **«Обновить»**
   в блоке Generation Agent.

Авторизация сохраняется в отдельном окружении HH Clicker. Уже выполненный вход в Codex
в другом приложении или терминале не подтверждает вход внутри HH Clicker.

| Статус генератора | Что означает |
| --- | --- |
| Готов | Сервис доступен, авторизация проверена; доступность модели выясняется при реальном запросе |
| Нужна авторизация | Нужно завершить вход в Codex |
| Недоступен | Нет связи с сервисом генерации |
| Browser Agent отключён | Агент не может проверить генератор из рабочего окружения |
| Данные устарели | Свежей проверки нет; обновите статус |
| Проверка не удалась | Сервис не подтвердил готовность; посмотрите пояснение |

Лимиты в интерфейсе — снимок состояния на момент проверки. Статус **«Готов»** не обещает,
что лимита хватит на любой объём задач или что конкретная модель доступна вашему аккаунту.

## 6. Поиски и сбор вакансий

### Сохраните поиск HH

1. Откройте hh.ru и настройте выдачу: запрос, регион, опыт, формат работы и другие нужные фильтры.
2. Скопируйте **полную ссылку** из адресной строки, включая параметры.
3. В HH Clicker откройте **«Поиски» → «Добавить поиск»**.
4. Вставьте ссылку, задайте название и максимум страниц за сканирование.
5. Проверьте привязанное резюме и нажмите **«Сохранить поиск»**.

Если в ссылке HH уже есть параметр резюме, приложение использует его для привязки.
Если параметра нет — выберите резюме вручную. Ручная локальная привязка не добавляет параметр
в ссылку и сама по себе не меняет выдачу HH.

Приложение сохраняет фильтры и сортировку, начинает с первой страницы и использует
100 вакансий на страницу. Максимум страниц ограничивает объём конкретного сканирования.

### Запустите сканирование

1. Выберите сохранённый поиск.
2. Нажмите **«Сканировать»**.
3. Следите за номером страницы и количеством собранных вакансий.
4. После завершения перейдите в **«Вакансии»**.

Сохранение поиска само по себе не запускает сканирование. Можно уйти на другой раздел
интерфейса — выполняющееся сканирование продолжится, пока окружение работает.

При ошибке прочитайте сообщение и устраните причину, затем используйте **«Повторить сканирование»**.
При редактировании поиска можно менять название, ссылку и лимит страниц; для другого резюме
нужно создать отдельный поиск.

> [!NOTE]
> Сканирование выдачи и загрузка полного текста — разные действия.
> Для аналитики нужен сохранённый текст вакансии; получить его без отправки откликов
> позволяет [холостой запуск](#dry-run).

<a name="vacancies"></a>
## 7. Отбор вакансий

### Основные вкладки

| Вкладка | Что показывает |
| --- | --- |
| **Все** | Общий список в текущем контексте |
| **Новые** | Вакансии для первичного разбора |
| **Избранные** | Отмеченные интересные предложения |
| **К отклику** | Сформированную очередь |
| **Пропущенные** | Предложения, которые вы отложили или исключили вручную |
| **Заблокированные** | Вакансии компаний из применяемого стоп-листа |
| **Откликнулись** | Вакансии с зафиксированным откликом |

Дополнительно доступны текстовый поиск, сортировка, фильтры релевантности и признаки вакансии:
анкета, письмо, стажировка и IT. Подробные сведения зависят от того, что удалось получить с HH.
Отсутствие сведений не следует читать как отрицательный ответ работодателя.

### Избранное, пропуск и очередь

- Отмечайте интересные вакансии и компании значками избранного.
- Используйте **«Пропустить»**, чтобы убрать неподходящее предложение из новых.
- Чтобы вернуть пропущенную вакансию, нажмите **«Вернуть в новые»**.
- Отметьте строки и нажмите **«Добавить к отклику»**, чтобы сформировать очередь.
- Во вкладке **«К отклику»** действие **«Убрать из очереди»** снимает выбор для отправки.

**Избранное и очередь — разные вещи.** Добавление в избранное не запускает отклик.
Добавление к отклику тоже не отправляет его немедленно: отправка начинается после подтверждения запуска.

Недоступное действие сопровождается пояснением. Например, для вакансии может требоваться анкета
или настройка письма. Не все предложения доступны для автоматического отклика.

<a name="stoplist"></a>
### Стоп-лист работодателей

Заблокировать компанию можно из вакансии или через **«Стоп-лист» → «Добавить компанию»**.
Проверьте работодателя и выберите область:

| Область | Где действует |
| --- | --- |
| Для резюме | Для выбранного резюме |
| Глобально | Для всех аккаунтов и резюме |

В разделе стоп-листа можно изменить область блокировки или разблокировать компанию.
После разблокировки актуальные вакансии возвращаются в **«Новые»**, но автоматически
в очередь откликов не добавляются.

<a name="relevance"></a>
## 8. AI-оценка релевантности

На странице **«Вакансии»** кнопка **«Оценить»** запускает оценку ещё не оценённых вакансий
из загруженного списка для выбранного резюме. Отметки строк для массовых действий
не являются отдельным списком для этой кнопки.

1. Проверьте аккаунт, резюме и сохранённый текст резюме.
2. Убедитесь, что Codex подключён и генератор доступен.
3. Нажмите **«Оценить»** и следите за прогрессом.
4. Используйте фильтр релевантности или сортировку **«По релевантности»**.

| Категория | Как использовать при разборе |
| --- | --- |
| **Цель** | Начать просмотр с предложений, которые модель считает наиболее подходящими |
| **Смежная** | Рассмотреть близкие направления и возможные компромиссы |
| **Проверить** | Прочитать вакансию самостоятельно: уверенного вывода недостаточно |
| **Мимо** | Проверить причину низкой релевантности, если вакансия всё же интересует |
| **Без оценки** | Для вакансии ещё нет сохранённого результата |

У результата доступно пояснение. Категория помогает организовать просмотр, но не заменяет
проверку требований и не гарантирует ответ работодателя. Оценка не отправляет отклики
и сама по себе не добавляет вакансии в очередь.

<a name="letters"></a>
## 9. Сопроводительные письма и настройки резюме

В разделе **«Резюме»** выберите нужное резюме и откройте **«Настройки откликов»**.
Значения используются как настройки по умолчанию и могут быть изменены перед конкретным запуском.

| Настройка | Что определяет |
| --- | --- |
| Обычное / резервное сопроводительное | Текст для работы без AI и разрешённого резервного сценария |
| Дневной лимит | Предельное количество откликов; поле принимает от 1 до 500 |
| Случайная пауза | Интервал ожидания между действиями |
| Генерировать сопроводительное для каждой вакансии | Включает AI-письма |
| Шаблон AI-письма | Постоянное начало, место генерации и завершение |
| Максимальная длина готового письма | Лимит всего письма, включая постоянные части |

Нажмите **«Сохранить настройки»**. Сохранение настроек не запускает генерацию или отправку.

### Обычное письмо

При выключенном AI используется обычное письмо. Оно должно быть самостоятельным текстом:
маркер `#AI_CHANGE#` в этом поле не допускается.

Например:

```text
Здравствуйте!

Меня заинтересовала ваша вакансия. Буду рад обсудить задачи и рассказать подробнее об опыте,
который указан в резюме.

Спасибо за рассмотрение отклика!
```

Это пример структуры: отредактируйте письмо под себя перед использованием.

### AI-шаблон

AI генерирует середину письма по тексту резюме и конкретной вакансии.
Начало и завершение остаются вашими. В шаблоне должен быть **ровно один** маркер:

```text
Здравствуйте!

#AI_CHANGE#

Буду рад обсудить задачи и подробнее рассказать о своём опыте.
```

Лимит готового AI-письма — **от 200 до 5000 символов**. В нём должно оставаться
не менее 200 символов для генерируемой части после учёта постоянного текста.

После подтверждения реального запуска готовое письмо может отправляться автоматически:
это не режим обязательного ручного согласования каждого сгенерированного текста.

### Что происходит при ошибке AI

| Ситуация | Поведение |
| --- | --- |
| Обычная ошибка генерации, резервное письмо заполнено | Возможно использование резервного текста |
| AI включён, резервное письмо пустое | Отклик без сгенерированного письма не отправляется; требуется разбор ситуации |
| Исчерпан лимит Codex | Запуск переходит на отдельную паузу; резерв требует явного подтверждения |
| Общая проблема авторизации или конфигурации | Очередь может остановиться до устранения причины |

Настройки и текст резюме фиксируются при создании запуска. Изменение настроек резюме
после старта не переписывает уже созданный запуск.

<a name="applications"></a>
## 10. Реальные отклики

### Подготовка

1. Выберите правильные аккаунт и резюме.
2. Просмотрите вакансии и сформируйте список **«К отклику»**.
3. Проверьте письмо и, если используется AI, состояние генератора.
4. Нажмите **«Запустить отклики»**.
5. В диалоге **«Запустить реальные отклики»** проверьте параметры.

### Параметры запуска

| Поле | Что проверить |
| --- | --- |
| Резюме | С каким резюме будут выполняться отклики |
| Максимум откликов | Не больше размера очереди и доступного остатка за день |
| Случайная пауза | Целые секунды, минимум 10; максимум до 3600; верхняя граница не меньше нижней |
| AI-шаблон | Корректный маркер и лимит длины, если генерация включена |
| Обычное / резервное письмо | Подходит ли текст для отправки работодателям |
| Холостой запуск | Для реальных откликов этот переключатель должен быть выключен |

Максимум откликов за запуск ограничен 500 и может быть меньше из-за остатка дневного лимита
или количества выбранных вакансий. Это ограничение приложения, а не обещание доступного лимита HH.

> [!IMPORTANT]
> Нажатие **«Запустить»** разрешает реальные действия на hh.ru и отправку писем работодателям.
> Для первого знакомства с отправкой достаточно одной осознанно выбранной вакансии.

### Во время обработки

Откройте **«Отклики»** и выберите запуск. Здесь показаны прогресс, результаты по вакансиям,
ошибки и задачи внимания. Во время работы не меняйте страницу в рабочей вкладке управляемого Chrome.

В блоке **«Подготовленные письма по вакансиям»** можно посмотреть подготовленный текст.
Подготовка письма сама по себе не подтверждает отправку отклика.

| Результат | Значение |
| --- | --- |
| В очереди | Вакансия ожидает обработки |
| В процессе | Текущее действие ещё выполняется |
| Успешно | Для запуска откликов зафиксирован успешный результат |
| Требует внимания | Нужны ваши действия или проверка |
| Ошибка | Обработка завершилась ошибкой; прочитайте комментарий |
| Пропущена | Вакансия исключена из обработки |
| Отменён | Элемент относится к отменённой обработке |

При потере связи сначала восстановите соединение и изучите историю. Если предыдущий отклик
не подтверждён, приложение при следующей допустимой попытке сначала проверяет его наличие на HH.
Не интерпретируйте сетевую ошибку как доказательство того, что сайт ничего не получил.

<a name="dry-run"></a>
## 11. Холостой запуск: загрузка текстов без откликов

Холостой запуск нужен для подготовки аналитики или знакомства с обработкой вакансий.
Агент открывает предложения и сохраняет доступные полные тексты.

1. Сформируйте очередь из доступных для выбора вакансий.
2. Откройте диалог запуска откликов.
3. Включите **«Холостой запуск — только загрузить тексты вакансий»**.
4. Укажите максимум вакансий и паузу.
5. Нажмите **«Загрузить тексты»**.
6. Просмотрите результат в разделе **«Отклики»**, где запуск помечен как холостой.

| При холостом запуске | Результат |
| --- | --- |
| Вакансии открываются | Да |
| Тексты сохраняются | Да, если удалось получить страницу |
| Письма генерируются | Нет |
| Отклики отправляются | Нет |
| Дневной лимит откликов расходуется | Нет |
| Очередь и статусы вакансий меняются | Нет |

За один холостой запуск можно обработать до 500 вакансий в пределах выбранной очереди.
Сохранённые тексты можно использовать для **«Аналитики рынка»**.

<a name="attention"></a>
## 12. Паузы, отмена и задачи внимания

### Управление запуском

| Действие | Что происходит |
| --- | --- |
| **Пауза** | Запрашивает приостановку обработки |
| **Продолжить оставшиеся** | Возобновляет оставшуюся очередь того же запуска |
| **Отменить** | Завершает текущий запуск без обработки оставшегося списка |

Пауза и отмена не отзывают уже отправленный запрос. Дождитесь результата начатого действия,
прежде чем делать вывод о состоянии отклика.

### Какие ситуации бывают

| Ситуация | Как действовать |
| --- | --- |
| Анкета работодателя | Открыть вакансию в управляемом Chrome, разобраться с анкетой вручную |
| Капча | Пройти её вручную в том же профиле браузера |
| Нужна авторизация HH | Войти в нужный аккаунт и проверить вход |
| Дневной лимит | Проверить доступный остаток и сообщение запуска |
| Несколько технических сбоев подряд | Прочитать причину, восстановить окружение и только затем продолжать |
| Лимит Codex | Дождаться доступности генерации либо явно выбрать резервное письмо |

Проблема отдельной вакансии может создать задачу внимания без остановки всей очереди.
Капча, потеря авторизации и три технических сбоя подряд приостанавливают запуск.
Заранее известная анкета может делать автоотклик недоступным ещё на этапе отбора.

### Как закрывать задачи внимания

В разделе **«Отклики»** найдите нужную ситуацию, прочитайте комментарий и выполните требуемое
действие на HH. Затем используйте доступное действие **«Готово»** или **«В пропущенные»**.

**«Готово»** закрывает ручную задачу, но само по себе не является универсальным подтверждением
того, что сайт принял отклик. Для вакансий с анкетами в каталоге есть отдельное действие
**«Проверить отклик и переместить в „Откликнулись“»**.

### Если закончился лимит Codex

В запуске отображается причина паузы и, если получено, ожидаемое время сброса.
Доступны:

- **«Повторить генерацию»** — вернуться к AI-сценарию;
- **«Продолжить с резервным письмом»** — явно разрешить резерв для остатка этого запуска;
- **«Отменить»** — закрыть запуск.

Продолжение с резервным письмом доступно только при непустом резерве.
Такое разрешение не включает глобальную замену AI-писем для всех будущих запусков.

## 13. Аналитика рынка и MD-отчёты

Этот раздел анализирует **сохранённый срез вакансий для вашего резюме**.
Он помогает увидеть формулировки технологий, навыков, доменов и названий должностей
в выбранных предложениях.

### Подготовьте данные

1. Соберите вакансии через сохранённые поиски.
2. Загрузите полные тексты, например [холостым запуском](#dry-run).
3. Подключите Codex и проверьте доступность генератора.
4. Перейдите в **«Аналитика рынка»**.

Одного присутствия вакансии в выдаче недостаточно: для анализа нужен сохранённый полный текст.

### Запустите анализ

1. Проверьте выбранное резюме.
2. Нажмите **«Запустить анализ»**.
3. При необходимости выберите конкретный поиск.
4. Задайте фильтр оценки вакансий или оставьте все, включая неоценённые.
5. Укажите число последних вакансий.
6. Проверьте предварительный размер выборки и дату загруженных текстов.
7. Подтвердите запуск.

Во время анализа видны прогресс и замечания извлечения. Приблизительное оставшееся время
появляется после первой готовой партии. Можно уйти со страницы: анализ продолжится на backend.

### Пауза и продолжение

- **«Приостановить»** — все уже выданные партии завершатся и сохранятся; новые не отправятся.
- **«Продолжить»** — продолжить сохранённый снимок без повторной обработки готовых партий.
- **«Отменить»** — окончательно закрыть анализ; для другой выборки создаётся новый.

Продолжение после ошибки или паузы ограничено сроком семь дней. Отменённый анализ
не становится готовым отчётом: наличие обработанных партий не означает, что MD уже можно скачать.

### Как читать отчёт

После завершения нажмите **«Скачать MD-отчёт»**.

| Показатель | Значение |
| --- | --- |
| Число вакансий | В скольких вакансиях встречается формулировка |
| Число компаний | Насколько широко она представлена у разных работодателей |
| Вес | Уменьшает влияние повторных вакансий одной компании |
| Названия должностей | Дополнительный контекст состава выбранного среза |

**Это не весь рынок HH.** Высокая частота не доказывает обязательность требования в каждой вакансии.
Обычный отчёт объединяет одинаковые названия без учёта регистра, но не сводит автоматически
падежи, сокращения и синонимы к одной технологии.

### Как использовать отчёт для резюме

Приложение извлекает факты и считает частоты; сравнение с резюме выполняется отдельно.

1. Скачайте MD.
2. Подготовьте актуальный текст резюме.
3. В блоке **«Разобрать отчёт с агентом»** нажмите **«Скопировать промпт»**.
4. Передайте промпт, отчёт и резюме в выбранный вами AI-чат.
5. Проверьте предложения по реальному опыту, прежде чем менять резюме.

Такой разбор позволяет искать недостающие формулировки и вопросы для уточнения,
но не должен автоматически приписывать вам опыт или инструменты.

<details>
<summary><strong>Проверочный MD: если нужны цитаты и контекст вакансий</strong></summary>

Обычный отчёт содержит компактные таблицы без полных текстов и цитат.
Проверочный вариант дополнительно включает подробности извлечения, цитаты и исходные тексты.

Откройте раздел аналитики с параметром `?debug=1`:

```text
http://<адрес-вашей-установки>/market-analysis?debug=1
```

Для готового анализа появится **«Скачать отладочный MD»**.
Используйте этот вариант, когда нужно проверить конкретный вывод; учитывайте объём и содержимое
перед передачей файла в другой сервис.

## 14. Уведомления и Telegram

### Системные уведомления и звук

Откройте **«Настройки»** веб-интерфейса:

Настройки общие для аккаунтов и резюме. Доступны события завершения запусков, автоматической
остановки, новых задач внимания, результатов оценки вакансий и анализа рынка.
Сообщение не отправляется на каждый обычный успешный отклик.

> [!NOTE]
> Браузерные уведомления работают, пока открыта вкладка HH Clicker.
> Сон компьютера, замороженная вкладка, запрет браузера или настройки Windows могут
> задерживать сообщения. Для звука сначала нужно взаимодействие со страницей.

### Подключите собственного Telegram-бота

1. Создайте бота через **BotFather** в Telegram и получите токен.
2. В **«Настройки» → Telegram** введите токен и нажмите **«Подключить»**.
3. Откройте предложенную ссылку на бота и нажмите **Start**.
4. Вернитесь в приложение: состояние подключения обновится.
5. Нажмите **«Отправить тест»**, чтобы проверить доставку.

Одноразовая ссылка действует 15 минут. Если она истекла, введите токен снова и создайте новую ссылку.
Поддерживается привязка личного чата. Если у бота настроен webhook другого приложения,
его нельзя одновременно использовать здесь в режиме long polling.

Токен хранится на backend и после подключения не показывается в интерфейсе.
Храните его как пароль и не прикладывайте к публичным обращениям.

### Что можно делать из Telegram

Бот показывает прогресс запуска и его итог. Для обычной очереди доступны пауза и продолжение,
для задач внимания — действия **«Готово»** и **«В пропущенные»**.
Для холостого запуска сообщения описывают загрузку текстов, а не отправку откликов.

После завершения или отмены итог можно **«Подтвердить»**, когда разобраны открытые задачи
и получен результат уже начатых операций. Подтверждение убирает промежуточные сообщения,
оставляя итоговую статистику.

Бот также показывает прогресс и итог анализа рынка; отдельного управления таким анализом
в Telegram пока нет. Ссылки на HH для ручного заполнения не присылаются:
анкеты, вход и капча выполняются в управляемом Chrome на компьютере.

<a name="assistant"></a>
## 15. Помощник на страницах тестов HH

В управляемом Chrome на поддерживаемых страницах оценки HH появляется кнопка **ASK CODEX**.
Для работы нужен доступный Generation Agent с подключённым Codex.

| Страница | Что делает помощник | Что остаётся вам |
| --- | --- | --- |
| Тест с вариантами ответа | Читает видимый вопрос, показывает ответ и подсвечивает вариант | Выбор ответа и отправка формы |
| Практическая задача с кодом | Показывает вариант решения с подсветкой в отдельной панели | Проверка, вставка кода, запуск и отправка |

Помощник запускается по вашему клику. Он не нажимает ответы, не изменяет редактор
и не отправляет решение самостоятельно. После перехода к другой практической задаче
предыдущий готовый ответ сбрасывается.

<a name="updates"></a>
## 16. Обновление, резервные копии и перенос

### Как обновить HH Clicker

1. Прочитайте описание нового релиза и требования перехода.
2. Завершите или приостановите текущие задачи и сохраните резервную копию данных.
3. Скачайте новый Setup EXE.
4. Запустите установщик поверх существующей установки.
5. После установки откройте лаунчер и дождитесь готовности сервисов.

Обычное обновление заменяет файлы приложения, сохраняя пользовательские данные и Docker volumes.
Понижение числовой версии не поддерживается. Наличие nightly той же числовой версии
не мешает установке соответствующего stable.

**Для перехода со старой ветки на 2.0 сначала установите и успешно запустите 1.12.0.**
Одной записи версии недостаточно: её миграции должны завершиться.
Backend 2.0 умеет распознавать эту историю без переименования служебных записей Liquibase.

### Какие данные нужно сохранять

| Данные | Что содержат |
| --- | --- |
| PostgreSQL | Аккаунты, резюме, вакансии, настройки и история |
| `%LOCALAPPDATA%\HH Clicker\data` | Конфигурация установки, локальные runtime и данные управляемого окружения |
| Volume авторизации Generation Agent | Отдельную авторизацию Codex |

Папка `application` содержит заменяемые файлы программы. Копия только этой папки
не заменяет резервную копию базы и пользовательских данных.

Для согласованного полного копирования локальных файлов сначала остановите окружение.
Базу PostgreSQL можно отдельно сохранять штатным `pg_dump` без остановки приложения.

> [!IMPORTANT]
> Installer не создаёт резервный дамп PostgreSQL автоматически.
> Восстановление предыдущих файлов приложения при ошибке установки не является откатом базы данных.

<details>
<summary><strong>Дополнительно: пример резервного дампа PostgreSQL</strong></summary>

Для стандартной установленной конфигурации имя контейнера — `hh-clicker-postgres-1`.
Если оно отличается, сначала уточните его в списке Docker и замените в примере.
Команды ниже выполняет пользователь в PowerShell; они сохраняют отдельный дамп, а не восстанавливают БД.

```powershell
$backupDirectory = Join-Path $env:USERPROFILE ("HH-Clicker-Backups\" + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $backupDirectory -Force | Out-Null

docker exec hh-clicker-postgres-1 sh -c 'pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc -f /tmp/hh-clicker-backup.dump'
if ($LASTEXITCODE -ne 0) { throw 'Не удалось создать дамп PostgreSQL' }

docker cp hh-clicker-postgres-1:/tmp/hh-clicker-backup.dump (Join-Path $backupDirectory 'hh-clicker.dump')
if ($LASTEXITCODE -ne 0) { throw 'Не удалось скопировать дамп' }

Get-FileHash -LiteralPath (Join-Path $backupDirectory 'hh-clicker.dump') -Algorithm SHA256
```

Файл содержит пользовательские данные. Храните его в закрытом резервном каталоге.
Дамп — только часть полного бэкапа: он не включает профиль Chrome, конфигурацию с паролями
и отдельную авторизацию Codex. Для уверенности в восстановлении нужна отдельная проверка
на тестовой БД, не поверх рабочих данных.

</details>

### Перенос на другой компьютер

Переустановка программы и перенос всех данных — разные операции. Для переноса нужны
база, соответствующая конфигурация и необходимые локальные данные/volumes.
Универсального мастера переноса в этой инструкции нет: состав копии зависит от вашей установки.

Не удаляйте Docker volumes и старую рабочую копию до проверки восстановленного окружения.

<a name="data"></a>
## 17. Где работают сервисы и куда передаются данные

| Действие | Где выполняется |
| --- | --- |
| Хранение каталога, настроек и истории | В локальной PostgreSQL |
| Управление запуском и обработка результатов | В локальных сервисах HH Clicker |
| Действия на hh.ru | В управляемом Chrome через интернет |
| AI-генерация и разбор | Через локальный Generation Agent с обращением к Codex |
| Сообщения бота | Через Telegram при включённом подключении |

**Локальный запуск не означает полностью автономную обработку без интернета.**
В AI-сценариях содержимое резюме, вакансии или видимой задачи передаётся в Codex
в объёме, необходимом для соответствующего запроса.

Профиль Chrome HH Clicker отделён от обычного личного профиля браузера.
Конфигурация, токен Telegram и дампы базы могут содержать чувствительные данные —
не публикуйте их вместе с диагностикой.

<a name="help"></a>
## 18. Если что-то не работает

### Сначала определите, где проблема

| Симптом | Что проверить в первую очередь |
| --- | --- |
| Не запускается окружение | Проверку компьютера в лаунчере, Docker и WSL |
| Не открывается веб-интерфейс | Готовность сервисов и адрес кнопки «Открыть HH Clicker» |
| Не выполняются действия на HH | Browser Agent, открытый профиль и авторизацию HH |
| Не работают AI-функции | Generation Agent, вход Codex, лимиты и сообщение ошибки |
| Нет вакансий для анализа | Наличие сохранённых полных текстов и фильтры выборки |
| Не приходят сообщения | Разрешения браузера, открытую вкладку или состояние Telegram-подключения |

<details>
<summary><strong>Docker или WSL не готовы</strong></summary>

Вернитесь в лаунчер, прочитайте результат подготовки и выполните предлагаемое действие.
Если потребовалась перезагрузка, перезагрузите Windows и снова откройте лаунчер.

Для уже настроенного Docker проверьте WSL 2 backend и Linux containers.
Если Docker предлагает собственное окно первого запуска, завершите этот шаг вручную.

</details>

<details>
<summary><strong>Порт занят или интерфейс открывается по неожиданному адресу</strong></summary>

Используйте **«Выбрать свободные порты»**, если лаунчер предлагает это действие.
После проверки открывайте интерфейс через лаунчер, а не по сохранённому старому адресу.
Лаунчер не завершает посторонние программы ради освобождения порта.

</details>

<details>
<summary><strong>На HH уже выполнен вход, но приложение просит авторизацию</strong></summary>

Проверьте, что вошли в профиль Chrome, открытый именно HH Clicker, и в нужный аккаунт.
Завершите вход или капчу вручную, затем нажмите **«Проверить вход»**.
Если статус остаётся неопределённым, прочитайте пояснение: страница могла не загрузиться
или её состояние не удалось распознать.

</details>

<details>
<summary><strong>Не находятся резюме</strong></summary>

В панели настройки аккаунта откройте управляемый браузер, войдите в нужный аккаунт HH
и используйте **«Я вошёл — найти резюме»** или **«Обновить список»**.
Проверьте, что выбраны нужные найденные резюме и нажата кнопка **«Добавить выбранные»**.
Проверка входа в разделе «Браузер» сама по себе не импортирует резюме.

</details>

<details>
<summary><strong>Не удаётся добавить вакансию в очередь</strong></summary>

Посмотрите пояснение у недоступного действия и статус вакансии.
Проверьте применяемый стоп-лист, наличие анкеты, требования к письму
и состояние предыдущей попытки отклика. Не все вакансии доступны для автоотправки.

</details>

<details>
<summary><strong>AI недоступен или его статус устарел</strong></summary>

Проверьте сервисы в лаунчере и вход Codex. В AI-настройках нажмите **«Обновить»**.
Если отключён Browser Agent, сначала восстановите его работу: через него проверяется
доступность генератора из рабочего окружения.

Вход в личном терминале не заменяет авторизацию в окружении HH Clicker.
Если сервис готов, но генерация отклонена, прочитайте сообщение о модели или лимитах.

</details>

<details>
<summary><strong>Запуск остановился или результат отклика неизвестен</strong></summary>

Откройте **«Отклики»**, выберите запуск и прочитайте причину паузы и комментарий вакансии.
Разберите задачи внимания и проверьте состояние на HH, если результат не подтверждён.

Пока начатая операция не получила результат, некоторые действия продолжения могут быть недоступны.
Не создавайте повторный реальный отклик только из-за ошибки обновления интерфейса.

</details>

<details>
<summary><strong>В аналитике нет данных или отчёт ещё нельзя скачать</strong></summary>

Проверьте выбранное резюме, поиск, фильтр релевантности и наличие полных текстов.
При необходимости сначала выполните холостой запуск для доступных вакансий.

Скачать готовый MD можно после завершения анализа. Если анализ приостановлен или завершился
ошибкой, используйте доступное продолжение. Отменённый анализ нужно создавать заново.

</details>

<details>
<summary><strong>Нет уведомлений или не подключается Telegram</strong></summary>

Для браузера проверьте разрешение уведомлений, выбранные события, открытую вкладку
и настройки Windows. Для звука сначала взаимодействуйте со страницей или нажмите проверку.

Для Telegram проверьте токен, личный чат, действие Start и срок одноразовой ссылки.
Бот с активным webhook другого приложения не подключается к этому механизму.

</details>

### Что приложить к сообщению о проблеме

Полезны версия HH Clicker, шаги до ошибки, ожидаемый и фактический результат,
текст сообщения и снимок соответствующего экрана.
Перед отправкой уберите токены, пароли, контакты и ненужное содержимое резюме.
Полную рабочую папку и дамп базы для первичного описания прикладывать не нужно.

<a name="faq"></a>
## 19. Частые вопросы

<details>
<summary><strong>Можно пользоваться без AI?</strong></summary>

Да. Поиски, каталог, отбор и обычные сопроводительные письма не требуют генерации Codex.
AI-письма включаются отдельно. Для AI-оценки, аналитики и помощника на тестах Codex нужен.

</details>

<details>
<summary><strong>Нужно оставлять компьютер включённым?</strong></summary>

Да, обработка идёт в вашем локальном окружении. Сон или выключение компьютера
не позволяют сервисам и браузеру продолжать обычную работу.
Закрытая веб-вкладка также не доставляет браузерные уведомления.

</details>

<details>
<summary><strong>Добавление в избранное или очередь сразу отправляет отклик?</strong></summary>

Нет. Избранное помогает организовать просмотр, очередь задаёт список для обработки.
Реальная отправка начинается после подтверждения запуска без включённого холостого режима.

</details>

<details>
<summary><strong>Можно собрать тексты и сделать анализ без откликов?</strong></summary>

Да. Используйте холостой запуск, затем создайте анализ по сохранённым полным текстам.
Сам анализ не отправляет отклики и не является автоматическим сравнением с резюме.

</details>

<details>
<summary><strong>AI-оценка и аналитика рынка — одно и то же?</strong></summary>

Нет. Оценка присваивает отдельным вакансиям категории релевантности для выбранного резюме.
Аналитика извлекает формулировки из среза вакансий и собирает частоты в MD.
Дальнейшее сравнение этого отчёта с резюме делается отдельно.

</details>

<details>
<summary><strong>Отклик на HH уже есть, а локально показана неопределённость. Отправлять снова?</strong></summary>

Сначала проверьте состояние на HH и комментарий предыдущей попытки.
Для неподтверждённых вакансий повторный допустимый запуск сначала проверяет существующий отклик.
Если доступно отдельное действие проверки, используйте его, а не ручное дублирование отправки.

</details>

<details>
<summary><strong>Удаление и переустановка — способ исправить любую проблему?</strong></summary>

Нет. Сначала определите причину по лаунчеру и результатам запуска.
Новая установка не заменяет резервную копию и не является автоматическим восстановлением данных.
Не удаляйте PostgreSQL volumes и авторизацию агента как универсальный способ исправления.

</details>
